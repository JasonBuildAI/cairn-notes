# Cairn Notes

[简体中文](README.md) | [English edition](https://jasonbuildai.github.io/cairn-notes/en/)

我学习 AI Agent 时整理的笔记，包括 Pi、OpenSandbox、四套 Agent 源码课，以及一组通用的软件工程基础。

在线阅读：<https://jasonbuildai.github.io/cairn-notes/>

## 笔记

- [Pi 1.3.0](https://jasonbuildai.github.io/cairn-notes/pi/)：模型调用、Agent 循环、上下文、工具与扩展，共 13 篇。
- [OpenSandbox 1.1.1](https://jasonbuildai.github.io/cairn-notes/opensandbox/)：沙箱生命周期、运行时、执行、网络与安全边界，共 14 篇。
- [DeerFlow 2.1](https://jasonbuildai.github.io/cairn-notes/deerflow/)：Gateway、Run 生命周期、LangGraph、Sandbox 与恢复，共 16 篇。
- [LoopX 2.1.1](https://jasonbuildai.github.io/cairn-notes/loopx/)：长程控制面、Turn 事务、Quota、验证写回与恢复，共 16 篇。
- [OpenClaw 2026.10.9](https://jasonbuildai.github.io/cairn-notes/openclaw/)：Gateway、Session、Agent Loop、工具审批与 Writer，共 16 篇。
- [Hermes Agent 0.22.5](https://jasonbuildai.github.io/cairn-notes/hermes/)：多前端宿主、Turn 生命周期、SessionDB 与扩展平台，共 16 篇。
- [工程基础](https://jasonbuildai.github.io/cairn-notes/engineering/)：从计算机系统、前后端、数据和部署，到模型、检索与 Agent，共 21 篇正文。

## 说明
