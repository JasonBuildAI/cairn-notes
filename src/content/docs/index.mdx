<div class="principle-grid">

		<span class="principle-index">01</span>
		<h3>版本固定</h3>
		<p>每套笔记绑定明确的 release 与 commit。先知道你读的是哪一版，再讨论“支持”与“不支持”。</p>
	</article>
	<article>
		<span class="principle-index">02</span>
		<h3>沿链路阅读</h3>
		<p>不按目录逐文件通读，而是追一次请求或任务如何穿过系统。每层只回答一个关键问题。</p>
	</article>
	<article>
		<span class="principle-index">03</span>
		<h3>标注边界</h3>
		<p>把“命令存在”“本机验证”“需要集群”分开写。能指出结论在什么条件下失效，才算真正理解。</p>
	</article>
