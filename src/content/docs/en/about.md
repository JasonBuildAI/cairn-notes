I am Jason. Here I put the notes I compiled while learning AI Agents; this is not a course for everyone.

:::note[English edition]
This English edition is machine-assisted from the Chinese original. Code, commands, and identifiers are preserved as closely as possible. If the two editions differ, the [Chinese edition](../) is authoritative.
:::

Usually, I first read the source code and run examples, record the verifiable parts, and then organize them into articles. Currently, there are source code notes for Pi, OpenSandbox, DeerFlow, LoopX, OpenClaw, and Hermes, as well as a set of general software engineering foundation notes. I will gradually add other topics as I learn them.

This is not official documentation for any project, does not include upstream source code, and does not guarantee completeness or long-term validity of the content. If you find errors, you are welcome to open an [Issue](https://github.com/JasonBuildAI/cairn-notes/issues). This repository does not accept Pull Requests.
