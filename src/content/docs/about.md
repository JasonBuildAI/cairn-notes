Cairn Notes 是一个长期学习仓库的公开层。

“Cairn” 是旅人留在路上的石堆：它不替你走路，只告诉你这里有人走过，方向大致可信。这个站点也一样——不追求把所有资料搬过来，而是把已经读通、跑过、能复述的部分写成可复核的路径。

## 只公开经过筛选的部分

一套笔记进入公开站点前，至少要满足四个条件：

1. **版本明确**：绑定具体 release 与 commit，避免“上次看的时候还是这样”。
2. **问题清楚**：每一章围绕一个可回答的问题展开，而不是按文件目录抄写。
3. **边界诚实**：区分读源码、跑过命令、需要集群、尚未验证的部分。
4. **可以迁移**：读者能把方法用到别的 Agent、运行时或系统上，而不是只记住某个 API。

这意味着公开速度会慢于本地积累速度。这里出现的内容，是已经成熟到可以被别人阅读、质疑和纠正的部分。

## 现在收录什么

- **Pi 1.3.0**：一个最小 Agent Harness。适合先建立模型调用、工具循环、会话、上下文和扩展的系统框架。
- **OpenSandbox 1.1.1**：一个 AI 执行平台。适合理解不可信代码在哪里运行、如何执行、如何联网、如何留下证据。

两套内容合起来，覆盖从“Agent 如何工作”到“Agent 的动作在哪里安全发生”的一整段链路。未来会增加其他主题，但不会为了看起来丰富而降低成熟度门槛。

## 这里不是什么

- 不是 Pi 或 OpenSandbox 的官方文档。
- 不是上游源码镜像，也不替代版本固定的官方仓库。
- 不是“读完就精通”的速成教程。它更接近一份需要边读边验证的系统地图。

如果你发现事实错误、版本过时或引用不当，欢迎在 [GitHub Issues](https://github.com/JasonBuildAI/cairn-notes/issues) 指出。对学习笔记来说，能被修正本身就是质量的一部分。
